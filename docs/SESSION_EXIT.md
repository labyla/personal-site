# Session exit checklist

Before handing work to the next session:

- [ ] Run the relevant focused checks and record their actual results.
- [ ] Run full verification when the scope or project policy requires it; record failures clearly.
- [ ] Update `FEATURES.json` only to reflect evidence-backed status.
- [ ] Update `PROGRESS.md` and `HANDOFF.md` with completed work, blockers, risks, and the next action.
- [ ] Remove temporary artifacts created during the session; do not remove user files.
- [ ] Leave the repository in a state the next agent can inspect and operate. If checks fail or work is incomplete, say so explicitly in the handoff.
